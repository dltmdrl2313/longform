# 당신이 평생 시작하지 못하는 이유 — Pretendard 수정본

- 길이: 정확히 5분 40초
- 형식: 1920×1080, 24fps, H.264 MP4, 스테레오 AAC
- 구성: 새 대본과 27개 절차적 2D 모션그래픽 시퀀스, 119개 한국어 자막, 남성 AI 내레이션, 새 오리지널 배경음악
- 화면은 카드 이동, 도식 전개, 목표 분해, 달력 변화, 문장 입력 등을 개별 요소로 애니메이션했습니다.
- 이전 실사 편집 영상과 음성·음악은 이번 편집에 사용하지 않았습니다.

## 자료와 이용 조건

그래픽과 메모 캐릭터는 이 제작을 위해 코드로 새로 그렸습니다. 참고 영상의 화면·캐릭터·음성을 복사하거나 완성본에 삽입하지 않았습니다.
음악과 작은 효과음은 외부 음원 샘플 없이 합성했습니다. 글꼴은 Pretendard 1.3.9입니다. 제목·강조 문구는 ExtraBold(800), 설명·하단 자막은 Bold(700)를 사용했습니다. SIL Open Font License 1.1을 동봉했습니다.
내레이션은 Microsoft Edge의 ko-KR-InJoonNeural 남성 합성음성입니다. 특정인의 음성 복제가 아닙니다. 이 음성의 유튜브 공개·상업 이용 권한은 확인되지 않았으므로 공개/수익화 전에 이용 조건 확인 또는 허용된 음성으로 교체가 필요합니다.

이 영상은 미루기의 가능한 원인을 설명하는 심리 에세이이며 개인을 진단하지 않습니다. 일정과 분량은 제안 예시입니다.

## 동봉 파일

- narration.txt: 내레이션 대본
- subtitles.ko.srt: 실제 음성 타이밍의 한국어 자막. MP4에는 이미 자막이 합성돼 있습니다.
- narration-male.mp3: 음악 없는 내레이션
- music-original.mp3: 오리지널 배경음악
- voice-settings.json: 음성 및 길이 조정 설정
- verification.json: 파일 검사 결과

묶음은 CapCut 프로젝트가 아니며 합성된 자막/도형을 개별 레이어로 직접 편집할 수 있는 파일은 아닙니다.
