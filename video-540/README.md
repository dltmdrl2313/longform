## 자료와 이용 조건

카드에는 그라데이션, 옆면, 부드러운 그림자를 적용했습니다. 메모 캐릭터에는 두께, 몸통, 접지 그림자와 신발을 추가했고 배경에는 그라데이션과 느리게 움직이는 도형을 넣었습니다. 그래픽과 메모 캐릭터는 코드로 새로 그렸습니다. 참고 영상의 화면·캐릭터·음성을 복사하거나 완성본에 삽입하지 않았습니다.
음악과 작은 효과음은 외부 음원 샘플 없이 합성했습니다. 글꼴은 Pretendard 1.3.9입니다. 제목·강조 문구는 ExtraBold(800), 설명·하단 자막은 Bold(700)를 사용했습니다. SIL Open Font License 1.1을 동봉했습니다.
내레이션은 Microsoft Edge의 ko-KR-InJoonNeural 남성 합성음성입니다. 특정인의 음성 복제가 아닙니다. 이 음성의 유튜브 공개·상업 이용 권한은 확인되지 않았으므로 공개/수익화 전에 이용 조건 확인 또는 허용된 음성으로 교체가 필요합니다.
